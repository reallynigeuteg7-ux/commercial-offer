# Facade Documents — КП и ПП для Windows

Отдельная программа с логотипом Facade Kazakhstan. Создаёт настоящие Excel 97–2003 XLS: КП и ПП отдельными кнопками, формулы и суммы, несколько товаров, общая цена комплекта.

## Заказы сайта

Кнопка «Подключить сайт» — вход с паролем администратора facade-kazahstan.vercel.app. Пароль в приложении не сохраняется; сессия входа хранится Electron. При запуске и по кнопке «Обновить заказы сайта» загружаются все заявки, включая архивные. Позиции одного заказа объединяются. Изменения документов сохраняются локально и не изменяют CRM. Последний список доступен без интернета. При завершении сессии требуется повторный вход.

## Сборка

Node.js 22.12+:

```
npm install
npm test
npm run build
```

Результат: desktop/dist/Facade Documents-win32-x64. Передавайте всю папку в ZIP. Запуск: Facade Documents.exe, установки Node.js на компьютере клиента не требуется.

FACADE_BUILD_TOOLS — альтернативный каталог инструментов сборки; FACADE_BUILD_OUTPUT — каталог результата.

## Данные

%APPDATA%/Facade Documents/orders: orders.json, резервная копия orders.json.bak и кэш site-orders.json. Резервные копии добавляются без замены текущих заказов. Эти данные, пароли и сессии не входят в репозиторий или дистрибутив.

Renderer sandbox/contextIsolation, узкий IPC; фиксированный адрес CRM. Программа не имеет цифровой подписи издателя. Обновление — замена папки программы, пользовательские данные сохраняются отдельно.
